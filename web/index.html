About

      
Universal AI Game Studio acquires a web game, mirrors it byte-identically,
      reconstructs a locally playable copy (URL rewriting + runtime interceptor), audits
      external services/branding, inventories assets with feasibility scores and verifies
      the reconstruction by actually playing it in headless Chromium.

      
    
        
  • Original files are never modified — everything is preserved under acquisition/original/.
    • 
        
  • Scores are evidence-based; uncertainty is visible, never hidden.
    • 
        
  • Cleanup changes are only proposed (audit report) — nothing is removed automatically.
    • 
        
  • APK builds run on GitHub Actions via acquire-build.yml (dispatch).
    • 
      

      
Use only games you own or are licensed to acquire, modify and redistribute.
